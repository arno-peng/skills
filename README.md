# skills

Personal Cursor skills repository.

## Structure

- `general/`: Reusable skills that are broadly applicable across projects and workflows.
- `personal-custom/`: Skills tailored to personal workflows, machine setup, or project-specific processes.

### General

- `cross-tool-ai-sync/`: Sync shared AI context across Codex, Cursor, and Claude.
- `md-browser-preview/`: Render Markdown to HTML and preview it in a browser.
- `project-ai-sync-bootstrap/`: Bootstrap shared AI context and sync scaffolding in a new repository.
- `task-subagent-planner/`: Turn task-marked requests into review-first subagent execution plans.

### Personal Custom

- `machine-dev-bootstrap/`: Restore the standard development environment baseline on this Mac.
- `parttime-work-log/`: Record and summarize personal part-time work logs.
- `sketch-to-android/`: Generate Android View-based UI code from Sketch designs.
- `sketch-to-compose/`: Generate Jetpack Compose UI code from Sketch designs.
- `work-progress-log/`: Track and summarize Siuper project progress notes.
- `zsh-setup/`: Configure and troubleshoot zsh themes, plugins, and prompt styles.

## Usage

Copy the desired skill folders into a project's `.cursor/skills/` or `.codex/skills/` directory, keeping each skill folder self-contained with its `SKILL.md` and companion assets/scripts.
